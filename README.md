# MON GIL : STAR DIVE — System Reverse Design (Visual Redesign v2)

GitHub Pages 정적 웹 기획서. 게임 개발/서비스: 넷마블몬스터/넷마블. 비공식 독립 분석 자료.

## 배포 방법
기존 GitHub Pages 저장소 최상위에 `index.html`, `theme-v2.css`, `script.js`, `README.md`를 복사해 덮어쓰세요.
**주의:** 기존 `style.css`는 더 이상 사용하지 않습니다. 새 테마 파일이 `theme-v2.css?v=2.0`으로 HTML에 연결되어 있습니다. GitHub Desktop에서 모든 파일을 포함해 커밋/푸시하세요.

## 변경 사항
- 기존 어두운 테마를 밝은 라일락·아쿠아·화이트 분석 리포트 테마로 전면 교체
- 사이드바·상단 바 밝은 테마 적용
- 메인 비주얼을 우측 대형 일러스트 카드로 구성
- 본문 카드·그래프·인터랙티브 조합 비교는 유지
- 모바일 반응형, 기존 12개 챕터 링크 유지
- 공식 미디어 이미지 외부 URL 사용: 차단 시 대체 그래픽 표시
