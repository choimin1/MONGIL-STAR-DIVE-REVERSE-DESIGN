# MON GIL : STAR DIVE — 웹 역기획서 1차 디자인 개편안

- 시작: 판타지 게임 소개형 히어로 (공식 보도자료 이미지 외부 참조)
- 본문: 화이트 / 라이트 블루 / 퍼플 기반 편집형 게임 기획 분석서
- 12개 분석 섹션과 3인 조합 인터랙션 및 자료 출처 유지

## GitHub Pages 게시
기존 저장소의 `index.html`, `style.css`, `script.js` 세 파일을 이 ZIP 내 파일로 교체하여 커밋한 뒤 Push origin. GitHub Pages 주소 및 설정은 그대로 유지됩니다.

## 유의사항
1. 첫 페이지 공식 미디어 이미지는 넷마블 공식 보도자료 서버의 외부 URL을 참조합니다. 외부 접근 차단 시 판타지 컬러 폴백 아트가 표시됩니다.
2. 넷마블몬스터 또는 넷마블의 공식 문서가 아닌 독립 역기획서입니다.
3. 확인된 사실 / 분석 가설 / 제안 기능의 구분을 유지합니다.
4. 분석 내용과 실제 측정하지 않은 QA 수치는 기존과 동일하게 보존했습니다.
