# 몬길: STAR DIVE — 시스템 역기획 웹 포트폴리오

## 개요
3인 태그·역할 및 속성 조합·다캐릭터 육성의 연결 구조를 공개 자료를 기반으로 분석하고, 새로운 파티의 실험 비용을 낮추기 위한 설계안을 제안한 비공식 역기획서입니다.

## GitHub Pages 배포
1. 새 **Public** GitHub 저장소를 생성합니다. 예: `MONGIL-STAR-DIVE-REVERSE-DESIGN`.
2. 이 폴더의 **내용물**인 `index.html`, `style.css`, `script.js`, `README.md`를 저장소 최상위에 넣습니다.
3. `main` 브랜치에 commit / push합니다.
4. GitHub 저장소 **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
5. 몇 분 후 `https://<계정>.github.io/<저장소명>/`에서 확인합니다.

## 구성
12개 섹션(표지 포함), 모바일 대응, 스크롤 내비게이션, 조합 유형별 인터랙티브 비교, 훈련장 UX 콘셉트, 데이터 측정 시트.

## 출처 및 주의
근거 목록은 웹사이트의 09 REFERENCES에 있습니다. 게임의 내부 설계 자료가 아니며, 일부 분석은 추정 및 검증 이전 가설입니다. 제안 기능은 현재 구현된 기능이라고 주장하지 않습니다.

## 로컬 열기
`index.html`을 브라우저에서 열면 됩니다. 외부 라이브러리 없이 정적 HTML/CSS/JavaScript로 동작합니다. Google Fonts를 사용하므로 오프라인에서는 시스템 폰트로 대체됩니다.
